READ THE BOUNDARY

A review aid. Your judgment stays in the loop.

Every regular file is byte-hashed, including unreferenced assets. UTF-8 files are checked for literal hosts, sensitive paths, execution patterns, and the SKILL.md tool declaration.

References are static Markdown links, path-like inline code, and @file references. Dynamic imports, runtime behavior, external content, and natural-language intent are not resolved. Links and scripts are never executed.

Excluded directories: .git and __pycache__. Symlinks, unreadable files, and exceeded scan limits stop the scan. Snapshots and reports may contain source text and secrets: share them deliberately.
